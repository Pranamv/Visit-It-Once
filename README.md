# AI Portfolio

A complete futuristic AI portfolio website built with HTML5, CSS3, JavaScript ES6, GSAP, Typed.js, Font Awesome, and optional Particles.js.

## Features

- GitHub-inspired dark UI with cyberpunk and Apple-style polish
- Full-screen responsive two-column hero
- Animated AI facial recognition scanner
- Circular profile photo and scanner photo using the same image
- Glassmorphism cards and HUD-style borders
- Animated background grid, particles, glow, and parallax
- Skill cards, project cards, vertical timeline, and contact form
- Loading screen, typing effect, counters, cursor glow, and mobile navigation

## Project Structure

```text
AI-Portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    ├── images/
    │   └── profile.jpg
    └── icons/
```

## Run Locally

1. Open `index.html` in a browser.
2. Make sure `assets/images/profile.jpg` exists.
3. Replace the social links and resume link with your real URLs if needed.

## Dependencies

Loaded from CDN:

- GSAP
- Typed.js
- Font Awesome
- Particles.js
- Google Fonts: Inter and Space Grotesk

## Notes

- The scanner uses the same profile image in both the left avatar area and the right AI scanner panel.
- The resume download button is wired to `assets/resume.pdf`.
- The design is fully responsive and optimized for desktop, tablet, and mobile layouts.
